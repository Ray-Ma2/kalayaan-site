広告運用ツールのプライバシーポリシー

KALAYAAN（以下「当方」）は、広告の運用を任されているお客様の広告アカウントについて、成果の確認と広告の作成・変更を行うために、Meta（Facebook・Instagram）の Marketing API を使う社内用のツール「ad-monitor」を運用しています。このページは、そのツールで扱う情報について説明します。

1. 扱う情報

当方が管理を任されている広告アカウントの、キャンペーン・広告の設定と、表示回数・クリック数・費用・成果などの集計値です。Facebook・Instagram を利用する個人を特定する情報は取得しません。

2. 使い道

広告の成果の確認、報告書の作成、広告の作成・変更・停止に使います。それ以外には使わず、第三者に提供・販売しません。

3. 保管と削除

当方の業務用の環境（Google Cloud ほか）で保管し、運用の委託が終わった時、またはご依頼があった時に削除します。

4. データの削除のご依頼

info@kalayaan.jp までご連絡ください。広告アカウントの管理者ご本人であることを確かめたうえで、30 日以内に削除し、その旨をお知らせします。
